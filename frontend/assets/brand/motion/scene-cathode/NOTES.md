# Cathode s'allume — notes

- **Cycle 16 s, 100 % CSS** compilé par `build.py` depuis des tables de beats en ms : OFF (LED rouge qui respire, double-blink d'anticipation avant le click) → boot CRT authentique (point qui flicker → ligne `scaleX (.2,.75,.3,1)` → bloom vertical `(.25,1.5,.45,1)` + flash blanc + flicker fluorescent du visage) → regards g/d avec anticipation inverse et overshoot → phase joyeuse (cœur pixel qui monte de l'écran, micro-hops) → somnolence → burst de neige (6 fenêtres de 73 ms sur 4 frames redessinées) avec sursaut → 3 zaps de chaîne (écrasement en ligne avec stretch d'anticipation 1.06 → snap, swap phosphore vert→cyan→magenta→teal via `currentColor` + `step-end`, re-bloom avec bounce 1.13/.96/1) → endormissement (zzz sur l'écran) → extinction ligne→point→rémanence qui reboucle sur OFF.
- **Frames pixel redessinées** : 3 coques à volume conservé (squash = tête −1 px + renflement +1 px sous l'écran + pattes écartées ; stretch = +1 px + pattes repliées) avec groupe `sync` step qui déplace aperture+antenne de ±1 px pour rester soudé ; 5 frames d'yeux et 6 bouches en demi-pixels (grille 16×12 dans l'aperture, « l'écran est un vrai écran ») ; le transform CSS ne fait que glisser les yeux (±1 px avec arcs en Y et retour centre pendant un blink).
- **Overlap partout** : la coque suit le regard avec ~150 ms de retard (pivot pieds), l'antenne est un ressort amorti à 8-10 keyframes déclenché par chaque événement (hop du boot ±16°, sursaut de neige ±18°, zaps ±3°, clunk d'extinction), la boule fouette en contre-phase 80 ms plus tard ; ombre au sol et halo ambiant (2 divs blur, couleur steppée avec le phosphore) asservis à la hauteur et à l'état de l'écran ; balayage CRT indépendant 2,7 s.
- **Testé image par image** via `index.html#t=MS` (getAnimations → pause) sur ~30 instants, 3 rondes de critique/correction : stem d'antenne invisible sur fond noir → gris deux tons, renflement du squash déplacé sous le verre, neige dédensifiée, yeux ^ épaissis, scanlines adoucies, couture de boucle vérifiée (t=50 ≡ t=15950).
- **Intégration** : `fragment.html` = un seul div `#ms-cathode` 460×420, classes `cath-*`, zéro JS, zéro sélecteur global ; `prefers-reduced-motion` fige une pose allumée souriante propre.
