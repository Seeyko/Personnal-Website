# NOTES — scène « La Rencontre » (ms-duo)

- **Cycle 17 s raconté en 6 actes sur une timeline maîtresse** : Cathode somnole (antenne tombée à 62°, zZ pixel qui flottent clippés par l'écran), Blip entre avec un vrai walk cycle 4 frames (patte lointaine assombrie #12851a pour lire l'alternance, rebond -4 px à l'apex de chaque passage, tilt 2↔4°), Cathode l'entend AVANT de le voir (twitch à 2,65 s, ressort d'antenne avec anticipation vers le bas puis overshoot à -10°), les pupilles le suivent avec inertie (overshoot -1,35 px puis settle), anticipation-crouch → happy hop -31 px → land squash + puff, sursaut de Cathode 280 ms APRÈS l'atterrissage, glitch de boot, cœur 3 frames qui pulse à la cadence rituelle 1,06 s, blush + dandine antiphase (x±3 / rotate∓4,5 / dips de transfert de poids), double-blink complice, hop-tour (flip scaleX au sommet de l'arc), sortie avec un skip de joie au 4e pas, regard qui traîne 600 ms, blink lent, l'antenne retombe (rebond amorti 68→55→65,5→62) et les zZ reviennent — boucle fermée.
- **Toutes les déformations sont des frames pixel redessinées** (14 pour Blip, 9 états d'écran pour Cathode) : squash/stretch à volume conservé, paupières en 2 frames, cœur small/big/mid — les transforms CSS ne font que déplacer/tourner ; swaps steppés (step-end) synchronisés aux pistes fluides (~40 keyframes sur bob/lean, cubic-bezier par segment : launch `.2,.7,.42,1`, chute `.53,.02,.8,.4`, pop `.25,1.5,.45,1`).
- **Hiérarchie et overlap partout** : Blip = x → flip → lean (origine 50 % 96 %) → bob → frames ; Cathode = bounce → lean → respiration 3,4 s → coque/antenne (fill-box, origine base de tige)/pupilles/écran clippé ; le lean de Blip settle 550 ms après l'arrêt du corps, les yeux de Cathode arrivent toujours 100-200 ms en retard, l'antenne kick 60 ms après chaque battement de cœur.
- **Jamais la boucle** : particules (cœur pixel qui s'échappe pendant le blush, étincelle du ressort, motes dérivantes), LED 1,7 s, wash rouge pulsé derrière le cœur, et une IIFE qui alterne un gag une itération sur deux (`duo-alt` : Blip fredonne une note ambre pendant la dandine).
- **Intégration** : poser `fragment.html` tel quel dans une page sombre (testé dans une page hôte étrangère : zéro fuite, tout est préfixé `duo-`/`#ms-duo`, pas de sélecteur global) ; taille native 460×420 px ; JS = une IIFE optionnelle de 3 lignes (la scène vit sans) ; `prefers-reduced-motion` fige le tableau iconique : Blip qui rougit devant le heartbit de Cathode.
