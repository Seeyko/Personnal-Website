Baseline was Perf 60 / A11y 94 / BP 96 / SEO 92 (homepage mobile), LCP 10.4s.

**Remaining gap**: retro90s mobile perf is gate-limited (its 89KB animation CSS +
the loading-veil reveal make LCP contention-sensitive; it hits 99 on a clean run
but dips under load). Definitive fix = remove the loading gate for retro90s like
default (inline per-theme critical hero CSS: silver bg + hero quote + hide SALUT),
so its LCP becomes a static paint immune to main-thread contention. Deferred to
avoid FOUC risk in the heavily-animated theme right before shipping.

**Measurement gotcha**: `npx lighthouse` left ~23 headless Chrome procs alive
across runs, starving CPU and tanking later scores. Kill `chrome.exe` between
runs for stable local numbers.

## Root causes
1. **LCP killer**: `body.loading` hides all content (`opacity:0`) until the JS chain (theme CSS+JS,
   content fetches) finishes → hero text paints at ~10s.
2. **Render-blocking head**: 5 local CSS + 3 Google-Fonts stylesheets (all 6 theme font families) +
   synchronous `analytics.js`.
3. **Images**: 8.5MB of PNG/JPG carousel images loaded during run; no WebP, no srcset, no width/height.
4. **JS**: ~15 non-deferred scripts; GSAP from CDN; unused/legacy/duplicated JS; PostHog blocking.
5. **SEO/Best practices**: no robots.txt / sitemap / canonical / OG / JSON-LD / favicon / manifest;
   prod nginx `try_files … /index.html` makes /robots.txt serve HTML.
